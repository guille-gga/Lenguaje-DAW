# Reglas de escritura XML

- Todas las etiquetas deben cerrarse: por cada etiqueta de inicio, siempre debe haber otra que la cierre. El XML no permite etiquetas como <BR> o <IMG> de HTML.

- En el caso de que haya una etiqueta sin contenido para abreviar la escritura , XML permite fusionar la etiqueta de inicio y de cierre incluyendo la barra / al final de la etiqueta 
- Se puede incluir elementos dentro de otros, cerrandolos correctamente: no se puede cerrar un elemnto padre, si no se han cerrado todos los elementos hijos.

//

Cuando un documento XML cumple todas las reglas anteriores, se dice que es un documento bien formado
