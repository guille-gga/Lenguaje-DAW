# Conceptos fundamentales de los documentos XML

**Los conceptos fundamentales son:**

- Elemento: palabra que define una marca que se puedeponer en el documento. Se cumplen las siguientes normas:
    1. Los nombres de los elementos no pueden tener espacios. Por ejemplo , el nombre LISTA PRECIOS seria incorrecto, mientras que la LISTA_PRECIOS sí estaria bien.

- Etiqueta: sirven para marcar una sección del documento. Para ello , la seccion se encierra entre una etiqueta de inicio y una etiqueta de fin
    1. Etiqueta de inicio : se escribe encerrando entre los simbolos </ y > el nombre del elemento.

- Contenido: es todo aquello que está encerrado entre las etiquetas de inicio fin de un elemento.

- Atributos: son palabras que aparecen de la etiqueta de inicio de un elemento y a las quew se les asigna un valor.

- Comentarios: son lineas de texto cuya unica mision es las de poner anotaciones libres para aclarar el significado del documentoy hacerlo asi mas comprensible a las personas que lo abran Se escribe en lineas que comienzan por < !-- y acaban en -->
